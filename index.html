PROJECTS

3MA reconnaissance Tool
A custom cybersecurity reconnaissance tool designed to automate both passive and active information gathering during the early stages of penetration testing. The tool integrates multiple reconnaissance techniques such as subdomain enumeration, DNS analysis, port scanning, technology fingerprinting, and service detection into a single streamlined interface. It helps security researchers and penetration testers collect valuable target information efficiently while organizing results into structured reports for further analysis.
Detect Phishing Website Using Machine Learning
A machine learning-based browser extension developed to detect and identify phishing websites in real time. The extension analyzes website features and behaviors to determine whether a website is legitimate or potentially malicious before the user interacts with it. The project combines cybersecurity concepts with machine learning techniques to enhance user safety and reduce the risk of credential theft and phishing attacks through an easy-to-use browser security solution.
